# PVC2Print

PVC2Print by BITBEAST PRIVATE LIMITED.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6a58d4e01bb2791cc1b574f3/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **PVC2Print** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6a58d4e01bb2791cc1b574f3/releases/latest) and reinstall.
